# 어흥이

화면 맨 위 가운데에 사는 공부 친구. 아기 호랑이 **어흥이**가 시험 D-day, 그날 수업, 과제 마감, 단톡방 공지, 날씨, 메모를 한곳에 모아 보여주고, 시험 전날 밤·당일 아침과 과제 마감 전에 알려 줘요. 텔레그램 봇을 연결하면 공지를 모아 오고 알림을 폰으로도 보내요.

[Coucou](https://github.com/Louis-CFM/coucou)(MIT)의 Windows 버전을 바탕으로 만든 **개인용** 포크예요.

## 설치

1. 이 저장소의 **Releases**에서 가장 최근 `Eoheung-Windows-setup.exe`를 받아 실행해요.
2. "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**을 눌러요. (인증서로 서명하지 않은 개인 빌드라서 그래요.)
3. 설치가 끝나면 어흥이가 화면 위쪽에 나타나고, 설정 창(공부 → 시험)이 열려요.

## 쓰는 법

| 하는 일 | 어흥이는 |
|---|---|
| 마우스를 화면 맨 위 가운데로 | 쏙 나와서 인사해요 |
| 클릭 | 열려요. 왼쪽은 지금 고른 알약의 카드, 오른쪽은 다른 알약들 |
| **오늘** | 날짜, 다음 시험까지 남은 날, 남은 수업, 이틀 안에 마감인 과제 |
| **시험** | 다가오는 시험과 D-day |
| **시간표** | 오늘 수업(수업이 끝나면 내일 것). ‹ › 로 날을 넘기고, **주간**을 누르면 월~금이 섬 전체에 펼쳐져요 |
| **과제** | `침구 레포트 11/3`처럼 치고 Enter → 마감일까지 자동으로 들어가요. 네모를 누르면 완료 |
| **날씨** | 지금 기온·체감, 최고/최저, 비 오는 시간, 3시간 간격 예보, 미세먼지, 옷차림 한마디 |
| **공지** | 텔레그램 단톡방·채널에 올라온 글. 누르면 전체 내용 |
| **D-day** | `국시 2027-01-16`, `방학 12/19`, `엄마 생일 3/14`(매년 반복)처럼 치고 Enter |
| **메모** | 한 줄씩 적고 Enter. 📌로 고정 |
| 트레이 아이콘 → 설정… | 시험·시간표·과제 편집, 날씨 지역·D-day·메모 정리, 텔레그램 연결 |
| 어흥이 오른쪽 클릭 | 옷장 (10월엔 마녀 모자, 12월엔 산타 모자) |
| 어흥이 세 번 연속 찌르기 | 어질어질 |

## 텔레그램

설정 → **텔레그램 · 공지**에 순서대로 나와 있어요. 요약하면

1. 텔레그램에서 **@BotFather** → `/newbot` → 받은 토큰을 붙여넣기
2. 단톡방 글을 다 받으려면 BotFather에서 `/setprivacy` → 내 봇 → **Disable** (그다음 봇을 방에 초대)
3. **내 폰 연결하기**를 누르고, 나온 숫자 4자리를 봇에게 1:1로 보내기

토큰은 Windows 자격 증명 관리자에만 저장되고, PC가 켜져 있고 어흥이가 실행 중일 때만 동작해요.

## 다시 빌드하기

`main`에 무엇이든 올리면(push) GitHub Actions가 Windows 설치파일을 새로 만들어 Releases에 올려요. 손으로 돌리려면 **Actions → 설치파일 만들기 → Run workflow**.

처음 설치할 때 들어가는 시간표·시험은 `windows/src-tauri/study-seed.json`이에요. 이미 설치한 뒤에는 앱 안에서 고친 내용이 그대로 남아요(`%APPDATA%\Eoheung\study.json`).
